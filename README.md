# 墨间 · Inkroom

沉浸式小说风的 AI 角色扮演（AIRP）前端，单文件 HTML，零安装。

- `inkroom.html`：完整页面源码。作为 claude.ai Artifact 发布时，页面通过 `claude.use("sample")` 用你自己的订阅额度调用 Claude，通过 `claude.use("db")` 在云端同步存档（手机也能玩）。
- 直接双击打开时会自动寻找本地后端 `http://localhost:8787`；找不到就是「离线模式」，可以编辑角色/预设/世界书、整理存档，但不能调 AI。
- `server/`：本地后端（Node）。用 Claude Code 登录的订阅额度调用**指定型号**（Opus 5 / Sonnet 5 / Haiku 4.5 / Opus 4.8 / 4.7 / 4.6 / Sonnet 4.6），并提供 SQLite FTS5 记忆检索与存档。见 `server/README.md`。

两种玩法对比：

| | claude.ai Artifact | 本地后端 |
|---|---|---|
| 安装 | 零安装，打开链接即用，手机可玩 | `cd server && npm install && npm start` |
| 额度 | claude.ai 订阅 | Claude Code 登录的订阅 |
| 模型 | 快速 / 标准 / 深思三档（具体型号由平台分配） | 精确选型号，楼层上会标注是哪一个 |
| 记忆检索 | 浏览器内全文索引（二元切分 + BM25） | SQLite FTS5 |
| 存档 | 云端同步 + 浏览器 | `server/data/state.json` |

## 第一版范围（核心 + 记忆系统）

- 预设、世界书（关键词 / 次级关键词 / 常驻 / 顺序 / 分组 / 绑定角色；可导入导出 SillyTavern 世界书 JSON）
- 角色库：手写、AI 随机生成、导入 SillyTavern V2/V3 卡（PNG / JSON，含场景、示例对话、备选开场白、系统提示、附加指令、深度提示、角色世界书、正则脚本、头像），导出 JSON / PNG 卡
- 正则脚本（兼容 ST Regex 扩展）：对 AI 输出 / 输入做替换，可只影响显示或影响提示词，可随卡绑定
- 前端渲染：AI 输出里的 ```html 块或裸 HTML 块渲染进沙盒 iframe（状态栏、前端卡）
- 本地缓存：IndexedDB 主存储（不受 5MB 限制），自动快照（生成 / 总结 / 回溯前，最多 30 份）可整体回滚，顶栏显示保存状态
- 提示词按缓存友好的顺序组装：预设 / 角色 / 常驻世界书在前，状态 / 检索 / 规则放在最后一条消息
- 一个世界最多 5 位角色（主角 + NPC），多世界平行存档
- 小说式楼层阅读，字号/字体/主题可调，快捷符号栏
- 抢话设定四档、回复字数四档、模型三档、灵感代写、续写、刷回复、编辑、回溯成分支
- 状态面板（时间/地点/天气/在场，心声默认折叠）、关系记录（含关系图与变化史）、记忆点
- 角色头像、世界背景图（自动压缩，透明度可调）；从人设里扫描 NPC 一键生成卡片与关系
- 世界书条目可绑定角色（只在该角色在场时生效）
- 记忆三层：可见楼层 → 总结写入世界书「总结/起-止楼」并隐藏 → 全文索引每次检索最相关 N 楼注入（默认 15，可调 5-30）；每积累 N 楼未总结会提醒（默认 20，可调）
- 上下文用量条（64 KB 上限）、最终提示词预览、一键备份/导入
- 小手机（➕ 面板）：WhatsApp 风格私聊与群聊、转账与钱包；角色像真人发消息（短句、连发、符合人设的语气）；聊天记录回流到剧情提示词，私聊只有当事双方知道，群聊成员共知
