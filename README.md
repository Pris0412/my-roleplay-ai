# 墨夜书房 · 沉浸式 AI 角色扮演

一个单文件的 AIRP 前端（`index.html`），像读小说一样走剧情，外加小手机、论坛、日记、状态面板、关系图谱与长期记忆。所有数据存在浏览器本地，一键备份成 JSON。

## 两种玩法

### ① 在 claude.ai 里玩（推荐，手机也行）
把这个页面发布成 Artifact 后直接打开。生成走你自己的 Claude 订阅额度，不需要 API key，也不需要后端。
存档会同步到你的账号（设置里可关），电脑和手机接着玩。

### ② 双击 `index.html` + 本地后端
本地后端用 Claude Code 的订阅登录来生成，可以选具体模型，永久记忆走 SQLite FTS5。

```bash
cd server
npm install
npm start          # 默认 http://localhost:3939
```

第一次先在终端运行一次 `claude` 完成登录。后端启动后会打印一个局域网地址，手机在同一 Wi-Fi 下打开即可。
在页面「设置 → AI 连接」里点「测试连接」。

自定义模型列表：`AIRP_MODELS="claude-opus-4-1:Opus 4.1,claude-sonnet-4-5:Sonnet 4.5" npm start`

## 功能一览

- **剧情**：楼层式小说阅读；刷（同一楼多版本）、编辑、分支、回溯、隐藏；抢话模式、篇幅、模型；灵感起草；快捷符号；Ctrl/⌘+Enter 发送
- **状态面板**：世界时间/地点/天气、角色情绪、心声默认折叠、NPC 在哪、关系
- **小手机**：WhatsApp（私聊/群聊，NPC 与角色各有自己的记忆边界）、转账与钱包、Instagram、论坛
- **时间推进**：跳过 N 天，生成每个人各自的经历、消息、动态、日记
- **记录面板**：关系图谱（点线看变化史）、记忆点
- **章节**：每次总结归档自动成为一章（AI 起章名），阅读区显示章节分隔与当前章，「章节」按钮可跳转或回溯到章首
- **记忆**：总结 → 自动归档到该世界的「记忆」世界书子区（如 `1-20`）；记忆索引与检索（每次 ≤10 楼；隐藏楼层仍可检索）
- **上下文预算**：超过时提示并显示被挤出的楼数；「提示词」按钮查看本次实际发给 AI 的全部内容
- **角色**：最多 5 个角色，每个角色多个世界；NPC 一句话生成；导入 SillyTavern PNG/JSON 角色卡（含角色书）
- **预设 / 世界书**：分块开关排序；常驻与关键词触发；作用范围可限定到某个世界
- **备份**：导出/恢复全部数据

## 记忆检索的实现说明

网页内置的是零依赖的 JS 二元分词倒排索引（浏览器里的 sql.js 官方构建不含 FTS5）。本地后端在线时，索引会自动镜像到 `server/memory.sqlite` 的 FTS5 表（trigram 分词），记忆页的检索会改走 FTS5。
